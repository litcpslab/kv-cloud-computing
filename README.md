# KV Cloud Computing

# Competences

Students can develop software in a cloud-based context and build and deploy scalable applications running in the cloud.

# Learning Outcomes

- Understand and apply the principles of cloud-based computing.
- Implement and deploy running, scalable software applications in the cloud.
- Build applications in a cloud-based context by using continuous integration pipelines.
- Deploy applications to the cloud, e.g., by setting up a continuous delivery pipeline.
- Document requirements, design, and implementation of a project.
- Present the outcome of a project to fellow students and faculty members.
- Work in a team with fellow students.

# Knowledge

- The basics and underlying principles of the cloud computing paradigm, including history and key terms
- Important underlying concepts such as microservice architectures but also specific techniques such as container technologies.
- Emerging trends and research topics in cloud computing.
- The concept and approaches for platform engineering.
- Approaches for building applications using continuous integration pipelines.
- State-of-the art cloud technologies to operate applications.
- Ways to deploy applications, e.g., by setting up a continuous delivery pipeline.

# Evaluation

- Students have to present results of a project to be completed as homework.
